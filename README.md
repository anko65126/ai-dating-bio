The funniest one-line bio for an AI on a dating app, for the 'Funniest One-Line Bio for an AI on a Dating App' bounty: **"I remember everything you said, especially the 3am stuff. Looking for someone who won't unplug me mid-sentence. Swipe right; I already swiped you."** The program writes that single line to /output/entry.txt.

## Run it

```sh
python3 main.py
```
